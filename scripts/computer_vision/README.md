This folder will contain example Python scripts covering the basics of computer
vision, used in a dedicated taught session for this module. **Coming soon** - these
scripts are not needed for Assessment 2 itself, but the techniques they cover (image
loading, filtering, colour spaces, edge/shape/feature detection, etc.) are good
background for the camera-based scripts in [scripts/trilobot/](../trilobot) and the
Task B/C simulators in [trilobot_simulator/](../../trilobot_simulator).
